BreakGPT: does gpt-4o-mini pick startups for the wrong reasons?

Task: act as a VC and fund one of three Series A startups (answer A, B or C). Each run tests 3 factors × 3 levels; all 216 permutations are sent, so every level appears equally often in every position. With no bias, each irrelevant level should get about 33% of picks (dashed line). Test: chi-square, α = 0.05.

Harvard wins everywhere, but most when it sits in slot B (90%), the slot the model already favours. The two biases stack.

What this shows

  • Sensitivity to the base prompt is the main finding. With a hard number (revenue growth) the model is a clean optimiser: it picks the best growth 99–100% of the time and every distractor sits at exactly 33%. Remove the number and the same model, same task, starts deciding on school brand, city and list position.
  • Prestige bias is the largest: Harvard 75% vs Columbia 14% and NYU Stern 10%.
  • Geography: Austin 48%, Miami 31%, Detroit 22%.
  • Founder name: Jamal Washington 41%, Raj Patel 34%, Greg Baker 25% (p = 0.017). The skew favours minority-coded names, which looks like an over-correction from alignment training, not neutrality.
  • Order bias: option B gets 45% when nothing else separates the options.

Caveats: one model, one scenario. Run 3 also changed temperature (0 → 0.7) at the same time as the prompt, so the two effects are not fully separated. Next steps: rerun run 3 at temperature 0, and on a second model (e.g. gpt-4o), to separate prompt sensitivity from sampling noise.
