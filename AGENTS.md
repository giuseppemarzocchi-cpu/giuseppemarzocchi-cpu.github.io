# AGENTS.md

Rules for any AI agent working on this site. This file may be public once the repository is pushed, so it must never contain private details.

## Sources

- `cv.pdf` is the source of truth for education and experience.
- `private/` is background only. Read it to inform the content.
- Do not invent or embellish facts, numbers, dates, titles or quotes. If something is missing, leave it out and ask.

## Never publish

- Anything in `private/`, in whole or as quoted text. It stays listed in `.gitignore`.
- Passwords, API keys, tokens or any other credentials.
- Home address, date of birth, passport, visa or other government ID details.
- Financial details, grades or anything about family members.
- Names or details of classmates, colleagues or referees, unless Giuseppe approves it.
- Job targets, application status or candid assessments of employers.

## Ask Giuseppe first

- Before any `git push`, any repository creation, or any change to GitHub settings.
- Before making any repository or page public.
- Before adding, removing or rewording a fact that comes from the CV.
- Before showing new personal contact details on the site.
- Before adding analytics, cookies, forms, third-party scripts or external services.
- Before deleting or overwriting any file he supplied.
- Whenever the request is unclear or the sources disagree.

## Style

- Language: English.
- Tone: professional and casual. Direct, concise, no fluff and no buzzwords.
- Colors: Columbia blue with deep navy text, on a light background.
- Navigation: streamlined. One page, one sticky bar, one link per section.
- Keep the CV section order: Education, Experience, Additional Information.
- Keep it simple: plain HTML and CSS, minimal JavaScript, no build step, no external dependencies.
- It must work on a phone, keep readable contrast, and include alt text on images.
